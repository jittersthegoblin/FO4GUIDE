# FO4GUIDE

An interactive Fallout 4 playthrough guide designed to prevent accidental faction lockouts, flag hidden timed quests, and make weapon modding easier to understand.

## Project goals

- Pick a planned ending: **Minutemen, Railroad, Brotherhood of Steel, Institute, or Undecided / maximum-content**.
- Adapt the recommended quest order to that route.
- Put large warnings in front of faction breakpoints such as **Tactical Thinking** and **Mass Fusion / Spoils of War**.
- Track completed quests with a persistent browser checklist.
- Explain which settlement/radiant quests are actually time-sensitive.
- Provide a beginner-friendly weapon-mod helper based on weapon type and playstyle.
- Keep spoilers adjustable.

## Source approach

The structure and base-game quest inventory are being built from Rina's copy of the *Fallout 4 Vault Dweller's Survival Guide* (Prima, 2015). The site does **not** reproduce the guidebook text. Quest facts and lockout behavior are summarized in original wording and cross-checked against current Fallout reference sources where the printed guide is ambiguous or incomplete.

The uploaded guide contains 286 PDF spreads/pieces. Its contents include dedicated sections for weapons/mods, main quests, Institute, Brotherhood of Steel, Railroad, Minutemen, side quests, radiant quests, workshops, and the world map.

## Current state

The first version is a working base-game foundation. It includes:

- route selector
- spoiler setting
- persistent quest checklist
- faction-danger warnings
- maximum-content route
- major faction ending routes
- timed-quest cheat sheet
- starter weapon-mod lab

More quest detail, side quests, exact weapon component/perk tables, companion quests, locations, collectibles, and DLC can be layered into the data files without rebuilding the interface.

## GitHub Pages

This project is plain HTML/CSS/JavaScript and requires no server or database. Enable GitHub Pages for the `main` branch/root directory to publish it.
